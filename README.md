# Real Madrid C.F. - Modern Themed Web Experience

An ultra-modern, regal Real Madrid CF themed web portal created with a clean white aesthetic accented by deep black and royal gold tones.

## 🌟 Visual Theme & Design Language
- **Dominant Palette**: Pristine White (`#ffffff`, `#f8fafc`, `#f1f5f9`), sleek Midnight Black (`#0a0b0e`), and Real Madrid Royal Gold (`#d4af37`, `#f3df8a`).
- **Typography**: Google Fonts `Cinzel` (regal Roman display for trophies & headings), `Outfit` (modern athletic geometry), and `Inter` (crisp UI body).
- **Aesthetic Details**: Frosted glassmorphism (`backdrop-filter: blur`), subtle golden glow effects, responsive cards with hover micro-interactions.
- **Floodlight Night Mode**: Built-in toggle between the classic pure white home kit aesthetic and the floodlit Santiago Bernabéu night mode.

## 🏆 Featured Sections

1. **Home (Hero)**:
   - Dynamic Santiago Bernabéu spotlight banner.
   - Slogan: *"¡Hala Madrid! ...y nada más"*
   - Live Trophy Ticker: 15 European Cups, 36 La Ligas, 8 World Titles, 103+ total trophies.
   - Marquee Match Card featuring an active real-time countdown to El Clásico against FC Barcelona.
   - Interactive Audio Fanfare: Synthesized Web Audio API fanfare celebrating club glory.

2. **Achievements Showcase (The Royal Trophy Room)**:
   - 15x UEFA Champions League / European Cup (Absolute world record).
   - 36x La Liga Championships (Spanish record).
   - 20x Copa del Rey.
   - 8x World Championships (5 FIFA Club World Cups + 3 Intercontinental Cups).
   - 6x UEFA Super Cup (Outright European record).
   - 13x Supercopa de España.
   - FIFA Best Club of the 20th Century award.
   - Filterable categories: All, Continental, Domestic, Worldwide.
   - Interactive Modal with winning years, scores, venues, and final highlights.

3. **Legends Hall of Fame**:
   - Curated cards for icons: Cristiano Ronaldo, Alfredo Di Stéfano, Zinedine Zidane, Raúl González, Iker Casillas, Luka Modrić, Ferenc Puskás, Sergio Ramos, Paco Gento.
   - Real-time search filter and position filter pills (Forwards, Midfielders, Defenders, Goalkeepers).
   - Interactive Legend Profile Modal with career statistics, iconic quotes, and full list of honors.

4. **History (The Regal Chronicle)**:
   - Interactive milestone timeline from 1902 to the present:
     - 1902: Genesis of Madrid FC & adopting pure white shirts.
     - 1920: King Alfonso XIII grants royal title ("Real").
     - 1947: Construction of Estadio Santiago Bernabéu.
     - 1955–1960: The Golden Quintuple (5 European Cups in a row).
     - 1998: La Séptima in Amsterdam.
     - 2002: La Novena & Zidane's Glasgow volley.
     - 2014: La Décima & Sergio Ramos 92:48 header.
     - 2016–2018: The Historic Modern Champions League Three-Peat.
     - 2024: La Decimoquinta (15th) at Wembley & The New Bernabéu.
   - Era navigation filters.

5. **Upcoming Fixtures & Match Center**:
   - Interactive tabs: Upcoming Matches, Recent Form, and La Liga Table Standings.
   - Marquee clashes: El Clásico (vs Barcelona), Champions League (vs Dortmund), Madrid Derby (vs Atlético).
   - Fan Match Simulator / Predictor with win probability and score generator.
   - La Liga Standings table highlighting Real Madrid in 1st place.

6. **Madridista Fan Zone**:
   - Web Audio API Anthem fanfare player with visualizer bars.
   - Spanish lyrics and English translation of "¡Hala Madrid y nada más!".
   - Madridista interactive trivia quiz with real-time feedback and score tally.

## 🚀 How to Run
Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Firefox, Safari):
```
file:///c:/Users/User/Desktop/satesto/index.html
```
No external build tools or installations are required.
